# Responsive Product Gallery

A responsive product gallery built using HTML, CSS, and vanilla JavaScript.

## Features

- Responsive product card layout
- Multiple product categories
- Category filtering
- Product search
- Large image preview using lightbox
- Previous and next image navigation
- Keyboard navigation
- Hover effects and smooth transitions
- Responsive design for desktop, tablet, and mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## Categories

The gallery includes products from:

- Electronics
- Fashion
- Accessories
